# Home Cards Theme

This Home Assistant theme sets the dashboard background.
It uses `#f4f3ef` in light mode and `#171a1c` in dark mode.

## Installation

Themes must be enabled in Home Assistant before installation.

1. Open HACS and select **Custom repositories**.
2. Add `https://github.com/vitalii-mural/home-cards-theme` with type **Theme**.
3. Download **Home Cards Theme**.
4. Open the dashboard editor. Edit the view and select the **Home Cards** theme.
5. Save the view.

The theme changes only the dashboard background. The card settings stay the same.
Home Device Cards is a separate package:
https://github.com/vitalii-mural/home-device-cards

## Updates

Install theme updates through HACS. Reload themes if the new colors do not appear.
Do not edit the installed theme file. Make changes in `themes/home_cards.yaml` in this repository.
